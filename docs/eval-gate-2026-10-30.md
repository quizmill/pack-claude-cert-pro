# Judge gate over the 200-question bank (2026-10-30)

The admin quality gate (`quizmill/admin` `evals/`: `lint --strict`, then
the three-pass judge over every question, then the thresholds in
`gate.json`) was run over all 200 questions and the bank revised until it
passed. Every question was judged on every pass; nothing was sampled.

**Model.** The gate pins `claude-fable-5-1`. On this run the Claude CLI
refused that model (`model_requires_usage_credits`, HTTP 429), so the
judge was run with `claude-opus-5-5` through the same three prompts and
the same thresholds. The result below is therefore an Opus 5.5 verdict,
not the Fable verdict the gate is configured for; the Fable gate still
has to be run once the model is reachable. The verdict cache for the
Opus run is kept beside the admin evals output so a re-run only
re-judges prompts whose input changes.

**Thresholds.** 0 lint errors, 0 fatal, 0 major, 0 key-not-confirmed,
0 solve-disagree, minor on at most 10% of questions.

|---|---:|---:|---:|

| verdict | FAIL | FAIL | PASS |

**What changed.** 68 questions were revised in round 1 and 24 of those
again in round 2. Keys, ids, domains, difficulty labels, the letter
balance and the select-two count are unchanged. Almost every finding
was `implausible-distractor` (51 of 73 flaws): a throwaway option a
learner can drop without knowing the subject. Each was replaced by a
tempting near-miss and the explanation now says why that near-miss is
wrong. The rest were absolute wording in distractors, explanations that
argued from a fact the stem never stated, and stems that spelled out the
answer's premises (d3-10, d4-05) or omitted a constraint the key relies
on (d2-14, d3-13, d3-37, d4-08, d4-11, d5-28).

**Still minor after round 2.** d3-09 (rebuttal of the MCP option could
be sharper), d3-37 (explanation leans on metadata the option does not
mention), d4-05 (the key is the one per-workload option), d4-14 (the
weak distractors are weak on their face). All four are within the
threshold and left for the next editorial pass.

**Choices-only.** The blind pass still hits the key on 99% of items,
with high confidence on 89% (91% before). The judge's stated cue is
almost always that the key is the balanced, evidence-based option while
the distractors are extremes. That is the shape of a scenario-judgement
exam rather than a leak of the stem, but it is the number to watch if
the bank is ever accused of being guessable.
